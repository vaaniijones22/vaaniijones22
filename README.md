## Development Philosophy

```txt
BUILD -> TEST -> VALIDATE -> AUTOMATE -> SCALE
```

I care about systems that are:

- **Useful**: built around real business needs, not demo theater.
- **Verifiable**: links, outputs, workflows, and claims should be checkable.
- **Repeatable**: if it works once, it should become a process.
- **AI-assisted, human-led**: AI accelerates execution, but strategy still needs judgment.
- **Production-minded**: clean enough to use, maintain, and improve.
